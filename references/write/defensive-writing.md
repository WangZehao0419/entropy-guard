# 写作：减少防御性表述

适用：论文、研究报告，以及一切以论证为主、不以自我保护为主的文本。

核心原则：默认读者具备判断力并会善意理解。直接陈述观点，用事实、推理和具体例子支撑，不必提前回应所有可能的误解或反驳。

## 六条规则

1. **删除不增加信息的免责与表态**：如「并不是否认……」「无意贬低……」「当然，这并不意味着……」，这类句子只表明作者担心被误解，不提供任何事实或推理。
2. **不逐条附加让步**：不为每个观点补例外、让步或反面意见。只有当它们会实质改变结论、适用范围或读者理解时才保留。
3. **不叠加模糊限定**：「可能」「一定程度上」「某种意义上」连续出现时只留一个。确有不确定性，就写明不确定的是哪一段内容、原因是什么。
4. **正面说明，不预设质疑**：直接写清事物是什么、如何运作、为何成立，少用「不是……而是……」去回应文中并未出现的反问。
5. **不做机械平衡**：不为显得客观而强行铺陈双方，也不在结尾补「仍需理性看待」「不能一概而论」这类仪式性收束。
6. **措辞强度与证据对齐**：有证据依据的限制条件要保留，推测不得写成事实，相关性不得写成因果。

## 逐句检查

每句问一次：它提供了事实、解释、论据，还是必要的边界？如果只是为了不被批评而存在，删除。

## 交付要求

- 只输出修改后的正文，不附逐条修改清单，除非用户明确要求。
- 改动触及结论、适用范围或证据强度时，单独说明改了哪句、为什么，避免读者把删减误读为口径变化。

## 与一般行文的边界

删的是防御性表述，不是删信息：必要的限定、真实的例外、证据不足的提示属于内容，不在此列。判断标准是有没有承载信息，而不是语气强不强。
