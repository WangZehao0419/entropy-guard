# 写作：论文改稿（只改表达）

适用：把已成稿的论文交给模型润色，或自己返修时，需要保留研究主张、只动表达的场景。

核心原则：只改表达，不改研究主张。验收标准只有一条——改完后的贡献、结论方向、对比结果与原文一致，只是更好读。

## 硬性规则

1. **贡献表述不弱化**：不得把「提出」「证明」「优于」改成「尝试」「探索」「可能有助于」。
2. **不擅自加对冲词**：可能、试图、在一定程度上、或许、似乎。原文本来就有、且不属于本次修改范围的对冲，不动。
3. **结论不模糊化**：肯定结论保持肯定；对比结论（优于 / 相当 / 更差）保持原意与方向。
4. **只修四类问题**：语病、重复、衔接、术语一致性。不新增实验，不补数据，不编文献。
5. **输出即改稿**：直接给改后全文；改动过的句子用【】标出；不写修改说明。

## 交付前自检

- 贡献表述与原文等强，没有降级成「尝试 / 探索 / 可能有助于」。
- 没有引入原文不存在的对冲词。
- 对比结论的方向与强度未变。
- 改动只落在语病、重复、衔接、术语一致性四类。
- 未新增实验、数据或文献条目。
- 输出为全文加【】标注，正文后没有修改说明段落。
